# Atriya-Concepts-Website
Objective: Designed and developed a responsive website for an interior design studio to showcase services and projects.
Technologies Used: HTML5, CSS3, JavaScript, Owl Carousel (for image sliders), Font Awesome (icons), FormSubmit (contact form).
Developed a responsive website to showcase interior design portfolios and services. Integrated Owl Carousel for dynamic project galleries and FormSubmit for client consultations.
